# Workshop SAI

Apresentação do **SAI — Sistema de Acompanhamento de Investimentos** (ANTAQ), em slides HTML.

## Como abrir

Abra o arquivo [`index.html`](index.html) no navegador. Ele carrega os slides da pasta [`sistema/`](sistema/) e permite navegar com as setas do teclado (← →), `PageUp`/`PageDown` e `F` para tela cheia.

## Estrutura

- `index.html` — capa / navegador dos slides
- `sistema/` — os 18 slides (`slide-01.html` … `slide-18.html`), o índice e as imagens
- `sistema/Imagens/` — logos e imagens usadas nos slides
